# Wirtualny Asystent Trenera: projekt aplikacji do symulacji i monitorowania parametrów życiowych sportowca
Projekt Inżynierski - WSB MERITO

## Opis projektu
Aplikacja chmurowa symuluje parametry życiowe sportowca w czasie rzeczywistym, uwzględniając modele fizjologiczne (m.in. wzór Sally Edwards, rezerwa tętna Karvonena, czy wskaźnik TRIMP).
